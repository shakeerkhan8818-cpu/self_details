# Student Engineer Portfolio

A responsive portfolio built with HTML, CSS, and vanilla JavaScript. Personalize the site by editing only `data.js`; no install or build step is needed.

## Get Started

1. Open the `NEW PORTFOLIO` folder in your editor.
2. Open `data.js` and replace the values marked with a pencil. Keep the quotes and commas, then save.
3. Copy portrait, project, achievement, and gallery images into `assets/`. Use paths such as `assets/portrait.jpg` in `data.js`.
4. Open `index.html` in a browser and refresh after each change. Keep images reasonably small so the page loads quickly.
5. If content is missing, check the browser console. A missing comma, quote, or closing bracket in `data.js` is a common cause.
6. Check the page at phone and desktop widths, and leave optional links or images blank when you do not have them.
7. To publish, push the folder to a GitHub repository. In **Settings > Pages**, choose **Deploy from a branch**, select your main branch and the root folder, then save.

## Files

- `data.js`: the only file students need to edit.
- `index.html`: accessible page structure.
- `style.css`: design tokens, responsive layout, and reduced-motion styling.
- `script.js`: renders portfolio data, validates required details, and adds optional scroll effects.
- `assets/`: local images and an optional resume.
